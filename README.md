## 一句话结论

- **有自己名下、能正常付外币的信用卡**：直接在 chatgpt.com 官网订阅，链路最短，售后找 OpenAI。
- **有能付款的外区 Apple ID**：在 iPhone 的 ChatGPT App 里内购，订阅归 Apple 管。
- **只有支付宝、微信**：选**正价代充**，也就是开通到你自己的账号、按官方档位开通的代充，付款前用下面的 [10 项清单](#代充平台怎么判断靠不靠谱10-项检查清单) 筛一遍。
- **共享账号 / 拼车 / 成品号**：最便宜，但账号不归你、对话记录别人能看到，OpenAI 也禁止共享账号，不建议用于正式工作。
- **主要用 Codex 写代码**：Codex 不单独卖，包含在 ChatGPT 会员里。先从 Plus 开始，用量不够再升 Pro。详见 [Codex 专题](docs/codex.md)。

## 为什么官网付款总是失败

国内用户在 chatgpt.com 订阅时，基本都卡在付款这一步：

1. **发卡地区限制**：官网支付通道对国内发行的银行卡（包括不少双币卡）拒付率很高；
2. **支付风控**：卡能用，从国内网络环境发起的付款也容易触发风控；
3. **不支持国内支付方式**：支付宝、微信、银联都不能直接用于官网订阅。

所以“充值”在国内基本等于三条路：找海外支付方式、走 App Store 外区、或者通过代充平台用人民币开通。

## 四种开通方式对比

| 方式 | 需要什么 | 账号归属 | 主要风险 | 适合谁 |
|---|---|---|---|---|
| 官网订阅 | 能付外币的境外信用卡 | 自己的账号 | 国内发卡常被拒付，换卡反复试也可能触发风控 | 有海外卡的人 |
| App Store 外区内购 | 外区 Apple ID + 当地付款方式或礼品卡 | 自己的账号 | 礼品卡来源不明可能是黑卡，兑换后 Apple ID 被锁 | 熟悉苹果外区生态的 iPhone 用户 |
| **正价代充** | 支付宝 / 微信 / USDT | **自己的账号** | 不是官方渠道，平台质量参差，要会挑 | 没有海外支付方式、想省事的大多数人 |
| 共享账号 / 成品号 | 无 | **不是你的** | 随时可能被封或被原主找回，聊天记录不私密 | 只做无隐私的临时体验 |

> 不管从哪条路付款，会员的模型、额度和功能都由账号的官方档位决定，跟你在哪里付款无关。区别只在于价格、速度和售后。

## Plus 和 Pro 怎么选

Pro 的三档功能基本一致，主要差别是**用量额度**。“5X / 10X / 25X”是商家为了好区分的叫法，OpenAI 没有公布固定倍数，额度以账号内显示为准。

| 你的用法 | 建议 |
|---|---|
| 每天聊天、写作、办公、偶尔写代码 | **Plus**，绝大多数个人用户的合理起点 |
| 每天用 Codex 写代码，Plus 额度经常用完 | **Pro 100** |
| 长时间跑 Codex、多个项目并行的重度用户 | **Pro 200** |
| 团队协作、需要全天候跑任务，或者对速度有硬需求 | **Pro 500** |

判断要不要升档，最可靠的办法是记一周：有没有因为额度用完而中断了真正要交付的任务。偶尔报错、网络慢都不算。详见 [套餐选择专题](docs/choose-plan.md)。

## 代充平台怎么判断靠不靠谱：10 项检查清单

付款前逐项核对，有 3 项以上做不到就换一家：

**账号安全**

1. ☐ 不要你的 ChatGPT 密码、邮箱密码、短信或邮箱验证码。
2. ☐ 提交账号信息的入口是平台自己的 HTTPS 页面，而不是发给客服私聊。
3. ☐ 开通到**你自己的账号**，而不是给你一个别人的号。

**价格和交付**

4. ☐ 价格明码标出，写清是一个月还是别的周期。
5. ☐ 写清已有订阅的账号怎么处理，不默认“会自动叠加”。
6. ☐ 不承诺“永不封号”“永久可用”这类连官方都做不到的事。

**订单和售后**

7. ☐ 有订单号和查单入口，游客也能查到自己的订单。
8. ☐ 有明确的质保规则，并写清哪些情况**不**在质保范围（例如账号被封）。
9. ☐ 只在平台生成的订单里付款，不要求私下转账。
10. ☐ 公开了至少一种能找到人的售后联系方式。

## 常见问题 FAQ

<details>
<summary><b>1. 没有海外信用卡，能开 ChatGPT Plus 吗？</b></summary>

能。最省事的是用支付宝、微信在正价代充平台开通到自己的账号，比如 [CallAI小铺](https://shop.callai.one/)；也可以走外区 Apple ID + 礼品卡，但要注意礼品卡来源。
</details>

<details>
<summary><b>2. 代充需要给账号密码吗？</b></summary>

正规平台不需要。CallAI小铺 只需要在自助兑换页按教程提交账号的登录 Session，用来给你的账号开通。Session 不要发到群聊、私聊或截图里；开通完成后，可以在 ChatGPT 设置里退出所有设备，让它立即失效。
</details>

<details>
<summary><b>3. 多久能开通？</b></summary>

付款后兑换码自动发放，提交兑换后通常 1 分钟左右开通，以兑换页面显示的进度为准。
</details>

<details>
<summary><b>4. 我的账号已经有 Plus，能直接续费或升级 Pro 吗？</b></summary>

大多数代充需要账号当前没有有效个人订阅。要续费或升级，先联系平台客服确认，别直接下“新开通”的单。
</details>

<details>
<summary><b>5. Plus 能用 Codex 吗？要不要另外买？</b></summary>

能用，Codex 随 ChatGPT 会员提供，不单独卖。Plus 够用就不用升级，经常撞额度再考虑 Pro。详见 [Codex 专题](docs/codex.md)。
</details>

<details>
<summary><b>6. 会员能当 API 余额用吗？</b></summary>

不能。ChatGPT 会员和 OpenAI API 是两套计费，开会员不会给开发者平台加余额。
</details>

<details>
<summary><b>7. Team 账号可以充吗？</b></summary>

先在 ChatGPT 里切回个人空间，再按教程获取 Session 提交兑换。
</details>

<details>
<summary><b>8. 为什么不推荐共享账号和成品号？</b></summary>

账号不归你，原主或卖家随时可能改密码、把号找回；同一个账号里的聊天记录和上传的文件，别人都可能看到；OpenAI 也禁止共享账号凭据。
</details>

<details>
<summary><b>9. 用 USDT 付款要注意什么？</b></summary>

链上付款是按到账金额精确匹配订单的。从交易所提币时手续费通常从数量里扣，到账会比订单少一点，导致无法自动确认。请按支付页金额转账，并另外加上提币手续费。
</details>

<details>
<summary><b>10. 掉订阅了怎么办？</b></summary>

先确认不是正常到期。在质保期内提前掉了，带上订单号、兑换申请编号和截图找平台客服。账号被封不在任何平台的订阅质保范围内。
</details>
