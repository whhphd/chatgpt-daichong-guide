# ChatGPT Plus、Pro 100、Pro 200、Pro 500 怎么选（2026）

> 返回 [ChatGPT 充值 / GPT代充指南](../README.md) · 最近核对：2026-10-23

## 先说结论

- **大多数人从 Plus 开始。** 日常聊天、写作、办公、学习、偶尔写代码，Plus 足够。
- **Pro 三档功能基本一致，差的是用量额度。** 只有 Plus 的额度反复卡住你的正经工作，才值得升级。
- **“5X / 10X / 25X”是商家的叫法。** OpenAI 按 $100 / $200 / $500 三档定价，没有公布固定倍数；额度规则官方也调整过，以账号内显示为准。

## 按用法选

| 你是谁 | 典型用法 | 建议档位 |
|---|---|---|
| 学生、办公族 | 查资料、写文档、润色、翻译、做表 | Plus |
| 独立开发者 | 每天用 Codex 写一两个项目，偶尔撞到额度 | Plus，撞额度多了再升 Pro 100 |
| 全职用 AI 写代码 | Codex 一开就是一整天，经常因为额度中断 | Pro 100 或 Pro 200 |
| 多项目并行的重度用户 | 同时跑多个 Codex 任务、长时间深度研究 | Pro 200 |
| 小团队、自动化任务 | 需要全天候运行，或者对速度有硬需求 | Pro 500 |

## 升档前先自查

1. **记一周**：有没有因为额度用完，真正要交付的任务被迫中断？偶尔一次报错不算。
2. **区分问题来源**：网络慢、页面卡、模型繁忙提示，换档也解决不了。
3. **先算账**：以 [CallAI小铺](https://shop.callai.one/products) 当前价格为例，Plus ¥109.98、Pro 100 ¥615、Pro 200 ¥1015、Pro 500 ¥3030。Pro 100 大约是 Plus 的 5.6 倍价格，确认额度确实不够再升。

## 已经有订阅，想换档怎么办

- 大多数代充只能给**当前没有有效个人订阅**的账号开通。
- 想从 Plus 升到 Pro，或者 Pro 换档，先联系平台客服确认怎么处理，不要直接下“新开通”的单。
- 通过苹果等应用商店订阅的，要等原订阅到期、账号恢复免费后再充。
